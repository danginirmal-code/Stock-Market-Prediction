Project Proposal
1. Background and Rationale for the Project:
In today's world, ensuring public safety and security is paramount, especially in crowded areas and
public buildings. This Capstone Project proposes the development of an advanced security system
leveraging networked security cameras and artificial intelligence (AI) to enhance facial recognition
capabilities. By deploying a network of interconnected cameras equipped with AI algorithms, the
system aims to identify and flag unfamiliar faces in public spaces or buildings, alerting
administrators to potential security risks in real-time.
2. Project Goals and Objectives:
● Design and deploy a network of security cameras strategically positioned in public spaces
or buildings to provide comprehensive coverage and surveillance.
● Develop AI-powered facial recognition algorithms capable of identifying familiar faces
based on predefined criteria, such as employees, residents, or authorised personnel.
● Implement machine learning techniques to continuously improve the accuracy and reliability
of facial recognition, minimising false positives and negatives.
● Integrate real-time communication capabilities between networked cameras to share facial
recognition data and coordinate responses to security incidents.
● Design a centralised monitoring and control interface for administrators to oversee the
security system, receive alerts about unfamiliar faces, and take appropriate actions.
● Enhance user privacy and data protection by implementing secure encryption protocols,
anonymising facial data, and complying with relevant privacy regulations.
● Conduct thorough testing, validation, and optimisation of the security system to ensure its
effectiveness, scalability, and usability in various environments.
3. Desired Outcomes/Deliverables:
● Deployment of a network of interconnected security cameras equipped with AI-powered
facial recognition capabilities in public spaces or buildings.
● Development of facial recognition algorithms trained to identify familiar faces and detect
unfamiliar individuals based on predefined criteria.
● Creation of a centralised monitoring dashboard for administrators to view live camera
feeds, receive alerts about unfamiliar faces, and review security incidents.
● Only one camera in action
● Provision of documentation, training materials, and user guides for administrators and
security personnel to understand and operate the security system effectively.
● Evaluation reports, performance metrics, and case studies demonstrating the effectiveness
and reliability of the facial recognition security system in enhancing public safety and
security.
4. Project Resources:
● Use of AI frameworks, deep learning libraries, and image processing tools for training and
testing facial recognition models.

5. Additional information
This Capstone Project addresses the growing need for advanced security solutions in public
spaces and buildings to mitigate security risks and protect individuals from potential threats. By
leveraging AI-powered facial recognition technology and networked surveillance cameras, the
project aims to enhance situational awareness, improve response times to security incidents, and
empower administrators with actionable insights to maintain public safety. Through rigorous testing,
collaboration, and innovation, the project seeks to establish a scalable and reliable security system
capable of adapting to evolving security challenges and safeguarding communities against
emerging threats.
